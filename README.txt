STATE 632 MIGRATION WEBSITE

Upload these four files to the root of your GitHub Pages repository:
- index.html
- apply.html
- config.js
- state632-bg.png

SETUP BEFORE PUBLISHING
1. Open config.js.
2. Replace https://discord.gg/REPLACE-ME with your Discord invite.
3. Create a form at https://formspree.io and replace https://formspree.io/f/REPLACE-ME with your form endpoint.
4. Update migrationDeadline in ISO format. Example for Toronto: 2027-01-01T00:00:00-05:00.
5. Commit the files and enable GitHub Pages from the repository's main branch/root folder.

IMPORTANT
- File uploads may depend on your Formspree plan and configuration.
- Never place a Discord webhook, bot token, API secret, or password in public GitHub files.
- Test the form after publishing.
